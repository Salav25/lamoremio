1

Сверить меню и цены

15 минут · менеджер

Меню в боте уже собрано — 120 позиций: пицца, роллы, бургеры, салаты, снэки, блины, соусы, напитки и десерты. Основа взята из вашего каталога ВКонтакте, а напитки и десерты — с сайта lamoremio.ru, в ВК их нет вовсе.

  1. Откройте демо-бота и пройдите по всем разделам.
  2. Скажите, где цены изменились.
  3. Скажите, каких блюд уже нет, а какие появились.

Прислать фото блюд

10 минут · любой сотрудник

Фото есть у 88 позиций. В первую очередь нужны шесть роллов — в каталоге ВКонтакте у них вместо блюда стоит общая картинка заведения, а на сайте эти файлы не открываются:

  • Запечённый «Банзай»
  • Горячий «Токио»
  • Большой ролл «Ламоре»
  • Холодный «Судоку»
  • Горячий «Мексика»
  • «Жёлтый дракон»
Подойдут обычные фото с телефона при дневном свете. Без них позиции тоже продаются, просто карточка будет текстом.

Во вторую очередь — фото напитков и десертов (25 позиций): они добавлены с сайта, но картинок там нет.

Заодно, если полезно: фото я брал с вашего сайта lamoremio.ru, и там часть картинок не открывается — сервер отдаёт ошибку вместо изображения. А те, что открываются, весят по 2 МБ каждая, поэтому сайт и грузится медленно. Если будете его обновлять — стоит заменить битые файлы и сжать остальные.

4

Открыть доступ к сообществу ВКонтакте

10 минут · администратор сообщества

Бот будет работать от имени вашего сообщества «Пиццерия Lamore Mio» — клиенты пишут привычной вам странице.

  1. Управление → Сообщения → «Сообщения сообщества»: включены.
  2. Управление → Сообщения → Настройки для бота → включить «Возможности ботов» и «Разрешать добавлять сообщество в чаты». Нажать Сохранить.
  3. Управление → Работа с API → Ключи доступа → создать ключ с правами «сообщения» и «фотографии» → прислать его мне.
  4. Управление → Работа с API → Long Poll API → включить, версия 5.199, во вкладке «Типы событий» отметить «Входящее сообщение».
  5. Создать отдельную беседу для заказов — не общий рабочий чат, чтобы заказы не терялись в переписке. Добавить туда сотрудников, которые принимают заказы.
  6. На странице сообщества нажать «Добавить в чат» и выбрать эту беседу.
Ключ доступа — как пароль. Присылайте его личным сообщением. В любой момент его можно удалить в том же разделе, и бот отключится.
5

Если нужен бот в MAX

до 3 дней · владелец

MAX разрешает ботов только верифицированным организациям. ИП подходит, физлицо — нет. Верификацию проходит владелец или человек с правом первой подписи.

  1. Открыть business.max.ru или мини-приложение «MAX для бизнеса».
  2. Создать профиль организации и пройти верификацию через Госуслуги (либо T-Business ID / Alfa ID).
  3. В кабинете создать бота: имя, аватар, описание.
  4. Отправить бота на модерацию — занимает до 48 рабочих часов.
  5. После одобрения в кабинете появится токен бота — прислать его мне.
  6. Создать в MAX чат для заказов и добавить туда бота — как и во ВКонтакте.
Меню, заказы и отчёты у ботов общие — заполнять всё заново не нужно. Учтите: заказы из ВКонтакте приходят в чат ВКонтакте, а из MAX — в чат MAX; написать в чужой мессенджер бот не может. Оплата за MAX — только после того, как бот реально заработает.
6

Запуск

в тот же день
  1. Я подключаю бота к вашему сообществу и вношу правки по меню.
  2. Вместе делаем тестовый заказ и смотрим, что он дошёл до беседы персонала.
  3. Показываю сотрудникам кнопки: «Принять» → «Готовится» → «Готов». Клиенту уведомления уходят сами.
  4. Объявляете бота клиентам — постом в сообществе и на кассе.
